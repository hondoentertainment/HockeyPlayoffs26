# CLAUDE.md

Guidance for Claude Code working in this repo.

## What this is

A single-purpose project: an Excel workbook that tracks the NHL 2026 playoff
bracket and auto-scores physical brackets submitted by players. The workbook
is generated by a Python script.

## Files

- `build_bracket.py` — generates `NHL_Playoffs_2026_Bracket_Scorer.xlsx`
  from scratch. All structural changes happen here.
- `NHL_Playoffs_2026_Bracket_Scorer.xlsx` — the generated artifact. Do not
  hand-edit; regenerate via `python3 build_bracket.py`.
- `README.md` — end-user instructions for the workbook.

## Regenerating the workbook

```
pip install -r requirements.txt   # or: pip install openpyxl
python3 build_bracket.py
```

This overwrites the `.xlsx`. Commit the regenerated file alongside any
`build_bracket.py` changes so reviewers can see the diff.

## Running tests

```
pytest
```

Tests open the generated `.xlsx` with openpyxl and assert structure
(sheet names, series count, named ranges, seed values). Run
`python3 build_bracket.py` before `pytest` if you've changed the builder.

## Key structural invariants

- `series.json` at the repo root is the single source of truth for series
  definitions, round labels, and default scoring config. Both
  `build_bracket.py` (Python) and `lib/series.ts` (TypeScript) read from it.
  Change series structure / point defaults there, not in the code.
- 15 series (8 R1 + 4 R2 + 2 CF + 1 SCF). Later-round series reference
  earlier-round winners by id via `team1Source` / `team2Source`.
- `NUM_PLAYERS` in `build_bracket.py` controls the number of pre-built
  player columns on the Picks / Scores sheets. Changing it is a destructive
  reset.
- Named ranges (`R1_PTS`, `R2_PTS`, `CF_PTS`, `SCF_PTS`, `GAMES_BONUS`)
  live on the Config sheet and are referenced by Scores formulas.
- Sheet order is enforced at the end of `main()`. New sheets must be added
  to the `desired` list.

## Conventions

- Yellow fill = user input cell. Green fill = formula-filled cell.
  Preserve this when adding new cells.
- Winner comparisons in formulas must use `UPPER(TRIM(...))` on both sides
  to tolerate case/whitespace differences between Picks and Bracket entries.
- Team-name input cells use a data-validation dropdown sourced from the
  `Teams` sheet. Don't bypass this when adding team-name inputs.
